# Roadmap

## v1: a real, usable first version

- [ ] The five-screen student flow (see design.md)
- [ ] Lab guide: equipment, mise en place bowls, time plan with overrun warning
- [ ] Automatic setup and cleanup tasks
- [ ] Team scheduling: split the plan between 1–5 cooks (see data-model.md)
- [ ] Auto-save in the browser; "start a new recipe" button
- [ ] Print-first lab guide (print or save as PDF), readable in black and white
- [ ] Works well on phone and Chromebook
- [ ] Hosted free on GitHub Pages at a simple link

## Later ideas (not v1)

- Turn in through Canvas, once the teacher thinks the app is ready
- Shared equipment limits (only one oven, one stand mixer)
- Several saved recipes per student
- Share a guide with the teacher by link (data in the link itself, so there's still no server)
- Paste recipe text to help fill fields (only if it doesn't undercut the reading)
- Teacher-made recipe templates for a lab
- Scaling servings up or down

## Open questions

1. Team size: is "up to 4 others" a maximum of 5 cooks in total?
2. Filling a bowl: let students estimate the minutes, or use a simple default (for
   example 1 minute per ingredient, plus prep time for chopping)?

## Answered

- Auto-add setup and cleanup: **yes**.
- How work is checked: **printed guide**, with the screen as backup. Canvas later.
- Name line on the printout: **no**.
- Default class period: **90 minutes**.
