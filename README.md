# Mise Planner

A dependency-free web app, embedded as an iframe in Canvas, that scaffolds Culinary 2
students' mise en place and prints a bowl grouping, an equipment checklist, and an
optimized cooking time sheet.

Build docs are the source of truth. **Start at `docs/00-START-HERE.md`.**
Work one ticket at a time from `docs/07-build-plan.md`, one commit per ticket.

Local dev: `python3 -m http.server 8000`, then open http://localhost:8000/index.html
